Isomorphic keyboard

A computer keyboard's staggered rows already form a (sheared) hexagonal grid. Assign +2 semitones to a step right and +5 to a step up-left (so up-right is +7), and you get the Wicki–Hayden layout used on concertinas: every chord and scale has the same shape in every key. The note of a key is just base + 2·col + 5·row.

This page is a small browser port of my native version, which reads keys straight from Linux evdev and drives a MIDI synth — and, on a Hall-effect keyboard (Keychron Q1 HE) running my custom QMK firmware, measures each keystroke's speed for velocity and lights up the keys of the current scale.

Try

  • Major triad: z c s (root, +4, +7). Slide the same shape anywhere to change key.
  • Major scale: z x c a s d f w — then the same shape from any other key.
  • Minor triad: x a d (D minor). Compare its shape to the major triad's.

Browsers can't see every key combination (some keyboards drop chords, and some shortcuts are reserved), and velocity is fixed. Touch and mouse work too.
